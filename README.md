- Идентификатор
- Заголовок
- Описание
- Дата Создания(partition key)
- Дата Удаления

Напишите C# скрипт который позволяет управлять задачами в бд. Полный CRUD.

2) Создайте ASP.Net MVC приложение:
- Страница Контакты
- Страница О Нас.
- Главная страница:
 - выведите набор карточек, с информацией о пользователях(Никнейм, статус, дата рождения, дата регистрации, последний вход). Пользователей подгружать из БД.(просто создайте сид, который при первом запуске добавляет пользователей в бд)
